# MultiChat CRM · Instaladores

Aquí solo se publican los instaladores de **MultiChat CRM** para Windows. El código fuente es privado.

**Para usar la app necesitas una clave de licencia** (formato `MC-XXXX-XXXX-XXXX-XXXX`). Pídesela a la administradora.

## Instalar

1. Entra en [Releases](../../releases/latest) y descarga `MultiChat-CRM-Setup-x.y.z.exe`.
2. Ábrelo. Si Windows muestra "Windows protegió su PC", pulsa **Más información → Ejecutar de todas formas**.
3. Abre MultiChat CRM, escribe tu clave de licencia y añade tus números de WhatsApp.

Las actualizaciones se instalan solas: la app avisa cuando hay una versión nueva.
